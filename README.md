Telecom Customer Churn Analysis & Prediction

Project Overview

This project focuses on analysing customer churn in the telecommunications industry and developing Machine Learning models to predict the probability of customers leaving a company.

Customer churn is an important business problem because losing customers can reduce revenue and increase customer acquisition costs.

Using Python and Machine Learning, this project explores customer behaviour, identifies patterns associated with churn, and develops predictive models that can help businesses improve customer retention.

Objectives

- Understand customer churn patterns.
- Identify customer characteristics associated with churn.
- Explore relationships between contract types, tenure, monthly charges, and churn.
- Build Machine Learning models to predict customer churn.
- Evaluate model performance.
- Provide business recommendations to improve customer retention.

Dataset

Source: IBM Telco Customer Churn Dataset.

The dataset contains:

- 7,043 customer records.
- 21 columns.
- Customer demographics.
- Account information.
- Contract details.
- Services used.
- Monthly and total charges.
- Customer churn status.

Target variable: "Churn"

- "Yes": Customer left the company.
- "No": Customer stayed with the company.

Project Workflow

1. Data Loading and Inspection

- Import the dataset.
- Examine its structure and dimensions.
- Inspect column types and values.

2. Data Cleaning and Preprocessing

- Check missing values.
- Identify duplicate records.
- Convert data types.
- Prepare categorical and numerical variables.

3. Exploratory Data Analysis (EDA)

Investigate customer churn through visualisations and statistical analysis.

Key areas:

- Overall churn distribution.
- Contract type vs churn.
- Customer tenure vs churn.
- Monthly charges vs churn.
- Internet service vs churn.

4. Machine Learning

Develop and compare two classification models:

- Logistic Regression
- Random Forest Classifier

The models will estimate the probability that a customer will leave the company.

5. Model Evaluation

Evaluate model performance using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC

6. Business Insights and Recommendations

Translate analytical findings into actionable recommendations for customer retention.

Expected Business Value

The analysis aims to help telecommunications companies:

- Identify customers at higher risk of churn.
- Understand factors associated with customer attrition.
- Improve customer retention strategies.
- Support data-driven business decisions.
